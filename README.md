## 从这里开始

- [React Bits](https://reactbits.dev) — 把文字动效、背景、交互组件放在同一站浏览，适合快速找首页的视觉主角。
- [拿了个国际小奖，我的个人网站演示](https://www.bilibili.com/video/BV1hYceeGEuq) — JIEJOE 的完整个人站演示，可沿作品集结构观察视觉、页面转场和交互的组合。

- [Magic UI](https://magicui.design) — 偏产品落地页的动效组件与完整布局参考，可从同一设计语言搭出整页。
- [Lusion：3D 视觉叙事工作室](https://lusion.co) — 品牌项目把 3D、交互与动画结合；适合比较沉浸首屏、产品发布和完整项目叙事。
- [Aceternity UI](https://ui.aceternity.com) — 从液态玻璃、背景着色器到交互 Hero，适合寻找醒目的首屏和产品展示。
- [网站离高级，还差一个跳转动画？](https://www.bilibili.com/video/BV1Nk4y1Q7pk) — 专门聚焦页面跳转动画，适合补充作品集站点从一个页面进入另一个页面时的连贯感。
- [Linear：产品工作流与官网展示](https://linear.app) — 官网直接呈现任务、状态、评论与团队工作流，适合研究复杂 SaaS 如何组织产品演示和界面层级。

- [UI 动效作品集：消消美食街](https://www.bilibili.com/video/BV1zSfPYwEev) — 已上线游戏的个人 UI 动效作品展示，适合看休闲游戏界面反馈和包装；简介有游戏地址。
- [Motion Examples](https://motion.dev/examples) — 官方示例覆盖画廊、卡片堆栈、页面切换、滚动和光标；可按具体交互找动效。
- [Recent（原 Godly）](https://recent.design/websites) — 网站与数字作品精选入口，按行业寻找整体风格；官方已说明接替 Godly。
- [GSAP Demo Hub](https://demos.gsap.com) — 磁性按钮、光标轨迹、Bento 滚动和 SVG 变形等同站检索，适合参考动画编排。
- [60fps：真实 App 动效库](https://60fps.design) — 按手势、元素和效果检索真实 App 交互，特别适合抽屉、按钮、图表与引导流程；部分内容需订阅。
- [WebGL Fluid Simulation](https://paveldogreat.github.io/WebGL-Fluid-Simulation) — 鼠标驱动的彩色流体实验，适合研究烟雾墨水式的动态背景与光标反馈。
- [Rive Marketplace](https://rive.app/marketplace) — 寻找会响应交互的矢量角色、按钮与界面元素；具体作品许可逐项确认。
- [Apple Health：健康引导拼合](https://60fps.design/shots/apple-health-longevity-intro-animation) — 不同健康主题的图形依次展开，再拼合为完整圆形图；参考分阶段引导如何汇总成一个视觉结论。
- [Runmo：里程圆环与统计切换](https://60fps.design/shots/runmo-distance-wheel-fill-interaction) — 切换年份时圆环进度和数字同步变化，适合运动统计、目标进度及时间范围比较。
- [Airbnb：触感标签按钮](https://60fps.design/shots/airbnb-tactile-tab-button-interaction) — 点击胶囊标签时先弹性缩小，选中高亮滑动，骨架卡片淡入实际内容；适合导航切换与加载反馈。
- [D3：可缩放旭日图](https://observablehq.com/@d3/zoomable-sunburst) — 按层级探索环状旭日图，适合文件、组织和内容分类的钻取界面；页面提供可编辑示例。
- [Codrops Demos Hub](https://tympanus.net/codrops/demos) — 独立实验、原型、布局和网站动画集中入口，适合持续追踪更大胆的视觉。
- [Earth：全球风场与海洋](https://earth.nullschool.net) — 地图支持风、洋流与波浪动画以及时间和图层切换，适合环境数据界面和流向视觉参考。
- [Codrops On-Scroll Typography](https://tympanus.net/Development/OnScrollTypographyAnimations) — 以滚动驱动大字排版，适合标题成为主要视觉的作品集或活动页。
- [Motion：App Store 卡片展开](https://motion.dev/examples/react-app-store) — 卡片扩展成全屏文章时，让图片和标题在两个状态间连续变形；适合详情页转场。

```sh
python scripts/build.py
python -m unittest discover -s tests
node --test tests/catalog.test.cjs
```
