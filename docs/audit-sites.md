# 整站 UI 与动效实证核查

核查日期：2026-11-03。逐个在浏览器加载主体，观看截图，并执行至少一项滚动、导航或交互。pass 表示已看到主体且完成所列交互；未验证的宣传效果在备注中明确收窄。

总计 23 条：22 pass，1 fail。

## 1. pass — [https://bruno-simon.com/](https://bruno-simon.com/)

- 操作：等待3D场景加载，点击开始，打开菜单阅读WASD/箭头提示，返回后按Up约1.2秒
- 实见：完整卡通3D庭院、小车、灯光、树木与立体名字出现；按键后车与镜头移动，字母被碰撞散开并出现爆炸反馈。菜单内有地图/驾驶说明与个人介绍。
- 备注：主体实际可操作；首次场景较重，截图曾超时一次，随后完成加载。非仅加载页。
