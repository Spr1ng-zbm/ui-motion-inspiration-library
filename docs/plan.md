# UI 灵感库 Implementation Plan

> 按用户要求直接执行已批准方向。采用 writing-plans 的任务拆分和 TDD，并由独立审查代理核验成品。

**Goal:** 高质量、多样、可长期维护的 UI 动效与界面索引。
**Architecture:** 来源 JSON → 规范化合并 → library.json/CSV/README/自包含 index.html。
**Tech Stack:** Python 标准库、原生 JavaScript/CSS，静态 GitHub 仓库。
**Spec:** docs/design.md

## Tasks

- [ ] 1. 平台检索：两路 research 代理负责视频与效果资源，主代理负责完整界面/交互案例。逐项记录原链接和证据等级；小红书仅已安装 CLI。
- [ ] 2. 先测试数据处理与搜索行为：URL 规范化去重、中文/英文多词匹配、组合筛选、空结果与不安全 URL 拒绝。运行失败后实现。
- [ ] 3. 创建浏览页与生成器：搜索、分类、收藏、随机发现、导出、离线目录。每条原链接与源码可访问；不自动播放远程视频。
- [ ] 4. 合并并审阅：排除重复/无关/证据不足项；生成 README、CSV、JSON；检查统计和链接状态，记录受限访问。
- [ ] 5. 独立代理审查：要求检查事实标注、功能、安全、移动端；修复重要问题，重跑验证。
- [ ] 6. GitHub：读取当前身份，新建任务专属仓库，仅提交整理结果；核验远端文件/仓库地址并交付。
