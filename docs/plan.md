# UI 灵感库 Implementation Plan

> 按用户要求直接执行已批准方向。采用 writing-plans 的任务拆分和 TDD，并由独立审查代理核验成品。

**Goal:** 高质量、多样、可长期维护的 UI 动效与界面索引。
**Architecture:** 来源 JSON → 规范化合并 → library.json/CSV/README/自包含 index.html。
**Tech Stack:** Python 标准库、原生 JavaScript/CSS，静态 GitHub 仓库。
**Spec:** docs/design.md

## Tasks

- [x] 1. 平台检索：两路 research 代理负责视频与效果资源，补充调查负责完整界面/交互案例。记录原链接和证据等级；小红书连接失败如实标注。
- [x] 2. 数据处理与搜索行为测试：URL 规范化去重、中文/英文多词匹配、组合筛选、空结果与不安全 URL 拒绝。
- [x] 3. 创建浏览页与生成器：搜索、分类、收藏、随机发现、导出、离线目录。原链接与源码入口可见，不自动播放远程视频。
- [x] 4. 合并并审阅：去重并标记索引线索；生成 README、CSV、JSON；记录核验范围和受限访问。
- [x] 5. 独立代理审查：事实标注、功能、安全与移动端检查；修复三项问题，单元测试与浏览器验证通过。
- [x] 6. GitHub：读取当前身份，新建任务专属仓库，仅提交整理结果。仓库上传成功；在线浏览页部署状态另行核验。
