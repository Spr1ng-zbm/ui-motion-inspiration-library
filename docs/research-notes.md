## 怎么使用

搜索效果或风格，按分类与平台筛选。卡片上的“画面已确认”表示本轮浏览器实际看到主体画面；具体操作范围见详情。已确认画面的作品优先排列。星标收藏保存在当前浏览器，可导出备份。

## 核验范围

- 浏览器画面与部分操作：已看到实际作品或触发具体交互，不代表完整测试全部状态。
- 页面内容与公开预览：读取对应页面与效果说明、预览结构，并检查 HTTP；不把 HTTP 200 当作运行成功。
- 视频：B站使用官方元数据核验；60fps 检查公开视频源，并对播放状态进行抽检。未逐一完整观看。
- 已知持续加载、脚本错误、挑战页和需要额外 API key 的新候选不纳入主库。

所有条目提供具体原链接与中文参考点。描述来自原作者页面及策展说明；编辑推荐不是客观评分。部分组件在文档页面中提供免费预览，源代码可能付费。WebGPU 条目明确标注硬件与浏览器要求。
