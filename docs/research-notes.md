# 检索与核验说明

检索始于 2026-11-02，整理完成于 2026-11-03（Asia/Taipei）。本轮目标是广泛收集有参考价值的 UI 界面与动态效果，覆盖不同风格、平台和实现方式。

## 怎么使用

- 想找整体风格：完整界面、灵感索引。
- 想做小而精的细节：微交互、图形与图标、文字与排版。
- 想做强视觉首屏：3D 与沉浸、粒子与背景、滚动与叙事。
- 想直接研究实现：选择 GitHub，或打开卡片上的源码入口。
- 想看中文视频：平台选择 B站。原站封面可能被防盗链，文字卡片和原链接仍可使用。
- 点击星标收藏，再进入“我的收藏”导出备份。收藏仅存在当前浏览器。

## 核验分层

1. **官方元数据**：例如 B 站官方公开接口返回的标题、作者、时长、封面，证明视频条目存在。
2. **页面信息 / 官方页面与仓库说明**：已读取原页面、官方文档或仓库。动态效果描述来自页面说明，未保证本轮实际运行。
3. **原平台搜索元数据**：检索到了原视频的标题或描述，但播放和正文读取可能受限。
4. **索引描述 / 第三方索引**：通过策展画廊或已读取索引确认线索。此类不是独立实看评测，具体来源在每条 evidence_url。

所有收录均有具体目标 URL，不用搜索页充数。推荐语是简短编辑说明，不是对原作者全部作品的质量认证。未宣称逐一完整观看视频、测试代码或性能。

## 平台限制

小红书已尝试使用已安装技能的 `python scripts/cli.py search-feeds --keyword 'UI 动效' --sort-by 最多收藏`。返回 XHS Bridge 扩展未连接，因此本轮 **0 条真实小红书笔记**；未编造笔记、互动数量或作者，也未把搜索入口计入库。

YouTube 页面和 oEmbed 在本机部分限流或 TLS 连接失败，部分视频只能核验搜索元数据或第三方索引。浏览器播放可用性需打开原视频确认。B站视频已由官方公开 API 验证。

## 图像与源码

缩略图 URL 来自原页面 OG/Twitter 元数据、官方视频 API 或明确标注的索引。它们是封面，并非本次截取的运行画面；默认随可视区域延迟载入，可关闭“显示原站封面”。本仓库不复制第三方视频和图像文件。

有源码入口不等于免费商用。React Bits、Motion+、Typed.js、部分 Codrops 示例有不同许可条件；具体记录见每条详情。第三方图片、字体、商标和代码的权利由原作者保留。
