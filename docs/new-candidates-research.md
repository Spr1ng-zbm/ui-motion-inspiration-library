# 新候选研究 · 2026-11-03

本文件对应 79 条候选，未修改现有主库。所有记录均为 candidate；HTTP GET 200 和公开媒体源不等于主体渲染、动画运行或视频播放通过。必须由主代理逐一浏览器验证后才能收录。

## 研究范围

35 个完整网站、产品展示或创作工具；30 段具体 App 交互录像；14 个原作者/官方独立动效与可视化。与开始时 173 条主库规范 URL 无重复。

使用网页检索发现原作者、具体作品与录像页面；通过原页元数据、正文、公开预览结构及官方示例入口确认目标归属。没有使用浏览器、截图或模拟交互，因此不宣称任何新增条目已运行。

60fps 的交互说明来自录像发布页，属于该录像的第一手说明，不代表 App 厂商文档。候选描述只概括页面所示主题；实际动作能力由后续浏览器核查决定。

## 核查优先顺序

1. 30 段录像已给出对应主视频源与海报，全部媒体 HEAD 返回 HTTP 200 / video/mp4；这不等于已播放。优先检查实际画面和播放进度。不要把录制画面当作可操作原 App。
2. tldraw、Excalidraw、Song Maker、Blobmixer、Fluid Paint 等直接体验，检查画布/编辑/参数的真实响应。
3. 完整站点逐个确认主体、导航与项目内容。产品官网必须有足够具体 UI 展示，纯营销文字落点不收。
4. deck.gl 两项为高风险候选；外部地图、GPU 或数据失败时应排除。Globe 与 Three.js 的空标题页需以实际画面验证，不能只看 HTML。
